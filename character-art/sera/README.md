# SERA — ARTIST FIRST (the replacement for V2/V3 procedural modeling)

The only source of new production character geometry is a completed, properly
licensed, professional 3D character asset or hand-edited Blender sculpt.
This folder is an intake system, **not a new autogenerated character**.

## Actual art sources (not substitutes for SERA)
- The official Blender Studio Human Base Meshes v1.4.1 asset bundle,
  49 MB, CC0, available from https://www.blender.org/download/demo-files/
  provides professional sculpt topology but is NOT a finished female fighter.
- Blender Studio Rain v3 is a complete, professionally art-directed character
  under CC-BY: https://studio.blender.org/characters/rain/v3/ . Its model and
  art direction are NOT SERA and must not be substituted into PolyFighter;
  it illustrates what high-quality hair, garments and sculpting look like.
- Custom licensed fighter from a professional 3D character sculptor, or a
  rights-cleared character from a premium supplier, is preferred for the
  realistic/stylized-credible target. Source grants must explicitly permit
  commercial game use, derivative modifications, and binary distribution.

Reference: public/reference/female-turnaround.jpeg in the repository.

## Minimum deliverables, in this exact order
1. Art direction: facial identity, black cohesive long hair/high ponytail,
   cobalt/graphite bespoke tailored fighting uniform. Show front, side,
   3/4, back, face and costume; judge with the SERA art reference.
2. Editable source with sculpted real facial planes, natural hair geometry
   and CLOTHING built and weighted as a garment. Do NOT replace a missing
   tailored outfit with boxes, strips, pipe cylinders or primitive overlays.
3. Retopologized body, outfits and hair and a single game deform skeleton;
   match the existing Mixamo-style joint naming, provide clear hands/feet.
4. Real UV and PBR materials: skin, eyes, fabric, boots, hair and armor
   have distinct roughness and preferably normal/detail maps; embed textures.
5. Capture multiple extreme motion shapes in Blender (guard, jab, heavy
   strike, high/low kick, crouch, knockdown) and fix weight painting before
   giving the model to the gameplay programmers.
6. iPhone Safari preview, 60fps as a target with two fighters and arena/VFX.
   Measure rather than promise. If expensive, author extra LODs in source.

## Concrete iPhone workflow
Open PolyFighter > MODEL VIEW > ARTIST ASSET LAB / GLB.
Use the iPhone Files picker to import the final game-ready .glb; inspect it
locally with physically based studio lighting and six camera angles.
The file stays ON DEVICE. Tap SAVE ACTUAL VIEW to obtain a real PNG.

Once the face, silhouette, hair and costumes genuinely look good, upload a
candidate.glb file and provenance.json into THIS directory on the working
branch through GitHub. Use provenance.example.json as the schema, replacing
all placeholders with genuine licensed rights. The candidate audit then runs
in GitHub Actions: structural rig/material gate plus six real Blender PNGs.
An optional artist-owned source can be exported, without any automated
anatomy creation, using:

blender -b --disable-autoexec --python tools/blender/export-artist-hero.py \
  -- source-character.blend character-art/sera/candidate.glb

GitHub's browser file upload has a size limit; for larger models, optimize
the game-ready GLB first or submit via supported developer tooling. An
unpacked or unlicensed model should NOT be added.

## Release is a separate, explicit decision

Do not copy candidate.glb into public/models/hero or merge this branch just
because an automatic technical gate passes. Finish true visual and mobile
testing first. For final sign-off, add approval.json using the sample format
and pin it to the exact GLB SHA256 printed by the provenance tool.
The 6 required art and device booleans start FALSE on purpose. Run:

node scripts/artist-approval-gate.mjs character-art/sera/candidate.glb \
  character-art/sera/approval.json

This gate is only an explicit human sign-off audit; it cannot judge whether
the face, hair or costume actually look good. The reviewer remains
responsible for the quality of images and real game screenshots.

## Targets, not guarantees

Preview hard cap: 32 MiB, 110k triangles and embedded PBR geometry.
Target game LOD roughly 30–55k tris / fighter after real profiling, face
textures up to 2K, smaller outfit maps if appropriate. Test thermal and
memory performance on actual iPhone; no artificial image generation as
substitute for Blender/WebGL screenshots.
